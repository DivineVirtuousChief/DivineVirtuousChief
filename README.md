## ENGINEERING PRINCIPLES

- **Evidence before assertion:** claims should be supported by inspectable records.
- **Fail closed:** unresolved exceptions do not silently pass release gates.
- **Human authority:** automated systems may analyze and recommend; authorized people retain consequential approval.
- **Traceability by design:** preserve provenance, decisions, versions, and audit evidence.
- **Privacy and security:** disclose only what is appropriate; protect credentials, sensitive data, and restricted project details.
- **Independent assurance:** distinguish implementation activity from verified outcomes.
